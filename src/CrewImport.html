Import Crew Makeup

Instructions

Paste the crew makeup data from the superintendent's Excel spreadsheet.

The system will update:

  • Location - Mapped from job header (Belgrade Dock → Bozeman)
  • Job Number - Base job number (e.g., 013-26) + individual position (.1, .2, etc.)
  • Job Classification - Based on role (Foreman, JL, Apprentice, GTO, etc.)
Note: Gray/future assignments in the spreadsheet will be ignored. Only active (colored) crews are imported.
