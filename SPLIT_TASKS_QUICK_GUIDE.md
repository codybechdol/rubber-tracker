# Split Tasks - Quick User Guide

**NEW FEATURE:** Divide tasks for the same location across multiple days!

## Problem It Solves

Before: All tasks for Eliston had to be on the same day  
Now: You can split them - some on 02/02, others on 02/05

## How to Use

### Quick Steps:
1. **Click** on a location card with multiple tasks
2. Click **"✂️ Split Tasks..."** button
3. **Check** which tasks to move
4. **Select** target day from dropdown
5. Click **"✓ Split Tasks"**

Done! Location now appears on both days with different tasks.

## When to Use It

✅ **Too many tasks for one visit** - Split across 2 days  
✅ **Urgent vs. non-urgent** - Move overdue to Monday, others to Thursday  
✅ **Training + swaps** - Separate training day from quick swaps  
✅ **Route optimization** - Match tasks with nearby locations on same day

## Example

**Eliston has 5 tasks:**
- 2 overdue glove swaps
- 1 training (CPR)
- 2 regular swaps

**Split it:**
- Monday 02/02: 2 overdue + training (3 tasks)
- Thursday 02/05: 2 regular swaps (2 tasks)

**Result:**
- Monday focused on urgent work
- Thursday is a quick trip for routine swaps

## Features

✔️ Smart merging if location already on target day  
✔️ Auto cleanup if you move all tasks  
✔️ Task counts update automatically  
✔️ Estimated time recalculates  
✔️ Right-click for quick access  

## Important

⚠️ Changes aren't saved until you click **"Apply to Schedule"**  
⚠️ Manual tasks (from Manual Tasks sheet) cannot be split  
⚠️ Single-task locations can't be split (just drag them instead)

## Tips

💡 Click location card first to **preview all tasks** before splitting  
💡 Group by urgency: overdue on early days, routine on later days  
💡 Group by type: training on dedicated days, swaps together  
💡 Experiment freely - nothing saves until you apply!
